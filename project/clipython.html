CipherVault

Uma ferramenta de cifragem em Python, nascida de um projeto escolar.

Python · RSA 2048 · AES-GCM

GitHub ↗

Em que consiste

Cifra ficheiros com cifragem híbrida: RSA para trocar as chaves, AES-GCM para os dados. Tem uma lista de contactos local.

Porque o fiz

Foi um projeto escolar. Não é o tipo de projeto que combina comigo, mas aprendi coisas importantes sobre cifragem.

O mais difícil

Manter a motivação para o acabar, ainda hoje: não me dá muita vontade.

Ponto da situação
