BoTokard

Um bot para a comunidade de um streamer.

Python · Discord.py · Twitch API · Gemini API · MySQL

Em que consiste

Bot em Python assíncrono. Fala com a API da Twitch, responde com a API Gemini, gere um jogo de cartas e guarda registos de auditoria em MySQL. Corre numa máquina virtual Proxmox.

Porque o fiz

O que mais gostei foi ver uma coisa que eu fiz a ser usada a sério, pelo streamer e pelos espectadores.

O mais difícil

Sem grandes dificuldades neste.

Ponto da situação

Concluído. É privado: não há código público nem demonstração.
